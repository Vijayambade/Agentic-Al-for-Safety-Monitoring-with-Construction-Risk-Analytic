## 2. Core Architectural Pillars

### 2.1 Live BIM Telemetry & Gantt Engine
- **Real-Time Stream:** Monitors active projects (e.g., *Skyline Financial Tower Phase 2*, *Metro Hub Underground Terminal*) with millisecond API latency tracking.
- **Dynamic Gantt Schedule:** Visualizes critical-path phase dependencies (Foundation, Structural Steel, MEP Rough-in, Exterior Enclosure, Interior Finish) with interactive milestone inspection.
- **Weather Risk Integration:** Automated weather advisory parsing alerts site engineers to high wind or storm conditions affecting tower crane operations.

### 2.2 Field Engineer Tablet Offline Protocol
- **Zero-Drop Data Engine:** When jobsite connectivity drops (e.g., subterranean tunnels or remote bridge piers), the system enters **Site Engineer Offline Mode**.
- **Local Cache Storage:** All site inspection sign-offs, QC checklists, material delivery receipts, and safety hazard flags are queued locally on the field device.
- **Auto-Reconciliation Sync:** Upon network restoration, queued transactions execute batch reconciliation to the cloud BIM repository with zero data loss.

### 2.3 Cloud Document Repository & OCR AI Compliance
- **AES-256 Cloud Vault:** Manages structural reports, CAD/DWG site blueprints, OSHA permits, and submittals with granular security tagging.
- **OCR AI Document Analyzer:** Automated optical character recognition scans uploaded contractor PDFs and drawings to verify structural tolerances (e.g., Caltrans specifications) and safety compliance.

### 2.4 Granular Role-Based Access Control (RBAC) & MFA
- **Dynamic Security Matrix:** Enforces real-time permissions across five operational roles:
  1. *Executive Stakeholder:* Financial portfolio oversight & change order authorization.
  2. *Project Manager:* End-to-end site operations, blueprint uploads, and safety overrides.
  3. *Site Engineer (Field):* Tablet-first field log creation, QC sign-offs, and material intake.
  4. *Safety & QC Inspector:* High-priority hazard logging, OSHA permit audits, and stop-work triggers.
  5. *API Systems Architect:* Telemetry webhook routing, API key issuance, and system diagnostics.
- **Hardware MFA Enforcement:** Protects executive workflows and change order approvals via two-factor verification.
